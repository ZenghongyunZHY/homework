# 海水养殖水质数据分析系统

## 项目简介
本项目基于 C 语言开发海水养殖水质数据分析系统，采用海南养殖基地 23203 组物联网监测数据，涵盖水温、盐度、溶解氧等 6 项水质参数。系统实现数据读写、预处理、统计分析、风险预警与线性回归预测等核心功能，可高效管理水质数据、识别养殖风险、预测水质变化，为智慧水产养殖提供数据支撑与决策参考。

## 功能模块
1. **数据读写模块**：支持从 CSV 文件读取水质数据，并将分析结果保存到文件中。
2. **数据预处理模块**：实现数据清洗、缺失值处理和异常值检测，确保数据质量。
3. **统计分析模块**：计算水质参数的均值、方差、最大值、最小值等统计指标，分析数据分布和趋势。
4. **风险预警模块**：基于设定的水质阈值，实时监测数据并发出风险预警，帮助养殖户及时采取措施。
5. **线性回归预测模块**：利用线性回归模型预测未来水质参数变化趋势，辅助养殖户进行科学决策。
